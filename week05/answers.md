1.Layers (Minimum). Which files in features/events/ import package:flutter? Which do not? Why?
The three files in `features/events/presentation/` (`event_card.dart`, `event_detail_screen.dart`, and `events_screen.dart`) import `package:flutter`. The files in `features/events/data/` and `features/events/domain/` do not.This is because the presentation layer builds the user interface using Flutter widgets. The data layer manages the event data and repository, while the domain layer defines the event model. Keeping these layers independent of Flutter makes the code easier to maintain, test, and reuse.
2.The connection (Minimum). EventsScreen never mentions InMemoryEventsRepository. Where is the connection made?
The connection is made in `lib/features/events/data/events_repository.dart`, inside the `eventsRepository` provider. It returns `InMemoryEventsRepository()`. The `EventsScreen` watches the events provider, which watches `eventsRepositoryProvider`, so the screen does not need to know about the concrete repository implementation.

4.Read the freezed model. Open lib/features/notes/domain/note.dart and note.freezed.dart. Which methods does Note have that are not written in note.dart? Find each one in note.freezed.dart. Why must you never edit note.freezed.dart?###

The `Note` class has generated methods that are not explicitly written in `note.dart`:

- `copyWith` – creates a new copy of a Note with selected fields changed.
- `operator ==` – compares two Note objects for equality.
- `hashCode` – generates a hash code for a Note object.
- `toString()` – returns a readable string representation of a Note.
- `map()`, `maybeMap()`, `mapOrNull()` – provide pattern matching based on the Note type.
- `when()`, `maybeWhen()`, `whenOrNull()` – provide pattern matching using the Note's field values.

These methods can be found in `note.freezed.dart`, mainly inside the `_$Note` mixin and the `NotePatterns` extension.

We must never edit `note.freezed.dart` because it is automatically generated by Freezed. Any manual changes can be overwritten the next time code generation runs. We should edit `note.dart` instead and let Freezed regenerate the file.
